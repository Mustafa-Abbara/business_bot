# business_bot — Agent-Powered Business Assistant

EECE 503P/798S (Agentic Systems), Assignment C3.

A chatbot that represents a fictional business: it answers questions from the business documents, routes each
message (general / lead / feedback), collects leads, and logs unanswered questions and feedback through tool calls.
It runs on Gemini through the `openai` SDK (OpenAI-compatible endpoint) and is served with a Gradio ChatInterface.

> 🚧 Work in progress — Stages 0–9 (environment, repo skeleton, business identity, context loading, first LLM call, persona + instructions + system prompt, tools + MCP-style schemas, tool-call loop, router, orchestrator + memory, Gradio chat UI) are complete.

## The business: EchoNest — *"Your memories, told your way."*

A fictional digital-memory studio that turns photos, voice notes and written memories into personalized digital
stories (timeline, captions, milestones, private shareable page). The agent is **Milo, EchoNest's Memory Concierge**.

> EchoNest doesn't store memories. It tells their story.

| Service | Price |
|---|---|
| Memory Capsule (one event) | $79 |
| Event Story (weddings, graduations, reunions) | $149 |
| Life Timeline (many years, one story) | $299 |
| Legacy Edition (life story + interviews) | $499 |
| Corporate Story | *no fixed price — quoted after a consultation* |

Team: Maya Haddad (Founder & Creative Director), Karim Saad (Memory Experience Designer), Lina Farhat (Client
Experience Manager).

**Information boundaries (by design).** The two knowledge files are deliberately different, so the agent's
grounding can be tested:

- **PDF-only facts:** photo limits, Legacy Edition duration, 50% deposit, password-protected pages, secure upload link.
- **Summary-only facts:** founding year, number of projects delivered, origin story.
- **Declined services:** film restoration, physical photo restoration, videography and deleted-file recovery are
  explicitly listed as *not offered*. The agent gives a grounded "no" and logs the demand with `record_feedback`.
- **Unknown topics:** albums, discounts, rush orders, VHS conversion, gift cards and a "Platinum" tier are mentioned
  nowhere. These are hallucination traps: the agent must not invent an answer, and should log the question.

The full test plan is in [`tests/knowledge_checks.json`](tests/knowledge_checks.json).

`me/about_business.pdf` is generated by `scripts/build_business_pdf.py` (needs `pip install fpdf2`, dev-only).

## Project structure

```
business_bot/
  me/                    # about_business.pdf + business_summary.txt
  scripts/               # build_business_pdf.py (regenerates the PDF)
  logs/                  # runtime JSONL logs (git-ignored)
  tests/                 # unit tests, knowledge checks, router cases
  business_agent.ipynb   # main notebook
  .env.example           # copy to .env and add your key
  .gitignore
  README.md
```

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows  (macOS/Linux: source .venv/bin/activate)
pip install openai python-dotenv pypdf gradio ipykernel
copy .env.example .env          # macOS/Linux: cp .env.example .env
```

Then put your Gemini key (from Google AI Studio) in `.env` as `GEMINI_API_KEY=...` — no quotes, no spaces.
In Colab, add `GEMINI_API_KEY` under **Secrets** instead and enable notebook access.

Open `business_agent.ipynb` and select the **Python (business_bot)** kernel.

Offline checks (no API quota used):

```bash
python tests/test_setup.py
python tests/test_business_files.py
```

## Library notes

The assignment mentions `google.generativeai` and `openai.ChatCompletion`. The first has been deprecated since
November 30, 2025, and the second was removed in `openai` 1.0. This project uses their supported replacements:
`client.chat.completions.create(...)` from the current `openai` SDK, pointed at Gemini's OpenAI-compatible endpoint.
